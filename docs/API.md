# JobPilot API reference

Generated by `python -m scripts.generate_api_docs` from the routes the application registers. Run the backend and open `/docs` for request and response schemas you can try out.

Authentication: none by default (local single-user mode). When `JOBPILOT_API_TOKEN` is set, every `/api` request must send `Authorization: Bearer <token>` (or `X-JobPilot-Token`); `/api/health` and the Gmail OAuth redirect stay open. See [DEPLOYMENT.md](DEPLOYMENT.md).

## answers

| Method | Path | What it does |
|---|---|---|
| GET | `/api/answers` | List Employer Answers |
| POST | `/api/answers/draft` | Draft an answer from verified facts. Missing facts are reported, never invented. |
| DELETE | `/api/answers/{answer_id}` | Delete Employer Answer |
| PATCH | `/api/answers/{answer_id}` | Edit the text. Any edit withdraws a previous approval; approve again afterwards. |
| POST | `/api/answers/{answer_id}/approve` | Approve Employer Answer |

## applications

| Method | Path | What it does |
|---|---|---|
| GET | `/api/applications` | List Applications |
| POST | `/api/applications` | Create Application |
| GET | `/api/applications/by-job/{job_id}` | Find a tracked record even when it isn't on the current UI page. |

| PATCH | `/api/applications/{application_id}` | Update Application |

| GET | `/api/applications/{application_id}/interview-prep` | Get Interview Prep |
| POST | `/api/applications/{application_id}/interview-prep` | Build a preparation plan from the real job. Existing progress is kept: only new items are added. |

| PATCH | `/api/applications/{application_id}/preparation` | Update Application Preparation |
| GET | `/api/applications/{application_id}/readiness` | Get Application Readiness |
